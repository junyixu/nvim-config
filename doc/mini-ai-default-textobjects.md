# mini.ai 默认文本对象

依据 `mini.nvim` 文档 `mini-ai.txt`（`@/home/junyi/.local/share/nvim/lazy/mini.nvim/doc/mini-ai.txt`）整理。当前配置在 `lua/plugins/mini.lua:22-34` 额外定义了 `,`（使用参数规范）与 `v`（驼峰/下划线子词）两个自定义文本对象，下表聚焦插件自带的默认条目，方便与本地扩展对照。

| 键位 | 名称 | `a` 文本对象 | `i` 文本对象 | 备注 |
| --- | --- | --- | --- | --- |
| `(` | 平衡 `()`（开） | 选中最近一对括号及其包含的内容 | 选中括号内部；忽略靠近开括号一侧的空白 | 同理适用于 `[`、`{`、`<` |
| `)` | 平衡 `()`（闭） | 与 `(` 相同 | 选中括号内部，但会包含闭括号一侧的空白 | 同理适用于 `]`、`}`、`>` |
| `[` | 平衡 `[]`（开） | 包含匹配 `[`…`]` | 同 `(` 行为 |  |
| `]` | 平衡 `[]`（闭） | 包含匹配 `[`…`]` | 同 `)` 行为 |  |
| `{` | 平衡 `{}`（开） | 包含匹配 `{`…`}` | 同 `(` 行为 |  |
| `}` | 平衡 `{}`（闭） | 包含匹配 `{`…`}` | 同 `)` 行为 |  |
| `<` | 平衡 `<>`（开） | 包含匹配 `<`…`>` | 同 `(` 行为 |  |
| `>` | 平衡 `<>`（闭） | 包含匹配 `<`…`>` | 同 `)` 行为 |  |
| `b` | 括号别名 | 依据上下文解析为 `)`, `]`, 或 `}` 的行为 | 同对应闭括号 | 统一入口，更易记忆 |
| `"` | 成对 `"` | `a"` 取包含引号的整段 | `i"` 只取引号内内容 | 匹配最近的一对引号 |
| `'` | 成对 `'` | 同 `"` | 同 `"` |  |
| `` ` `` | 成对 `` ` `` | 同 `"` | 同 `"` |  |
| `q` | 引号别名 | 解析为 `"`, `'`, 或 `` ` `` | 同对应引号 | 优先匹配最近的成对引号 |
| `?` | 用户提示 | 包含用户输入的起止标记 | 仅包含两标记之间的文本 | 每次操作都会提示输入左、右字符串，适合快速临时范围 |
| `t` | 标签（HTML/XML） | 选中最近 `<tag>…</tag>` 整个节点 | 选中标签内内容，不含标签本身 | 支持嵌套标签 |
| `f` | 函数调用 | 选中函数名及其括号参数 | 仅选中参数部分（括号内） | 函数名默认允许字母/数字/下划线/点 |
| `a` | 参数 | 选中离光标最近的一个参数（含周围分隔符） | 仅选中参数净内容，不含逗号与空白 | 识别 `()`, `[]`, `{}` 中的逗号分隔参数并跳过嵌套括号/引号 |
| 非拉丁字符（例：`_`, `*`, `,`） | 默认分隔符 | `a` 包含分隔符本身以及右侧块 | `i` 退化为分隔符本身 | 对任意非 `[A-Za-z]` 键位生效，便于把特殊字符视作“分隔”文本对象 |

- 所有默认文本对象都支持 `v:count` 与连续应用：例如 `va)` 后接 `a)` 会扩展到下一层。
- 括号类文本对象的 `a` 范围总是包含外层界定符，`i` 则去掉界定符；是否保留临近空白取决于按键是开括号还是闭括号。
- 参数与函数调用的精确识别依赖 Lua 模式匹配（非语法树），在极端字符串/注释场景下可能出现误判，可通过 `custom_textobjects` 覆盖。
